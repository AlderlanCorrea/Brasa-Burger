# Brasa Burger

Landing page de uma hamburgueria artesanal, criada para apresentar hambúrgueres caseiros, ingredientes selecionados e uma experiência de pedido simples e atrativa.

## Sobre o projeto

O Brasa Burger é um projeto visual com foco em:

- destacar o cardápio e os hambúrgueres da casa;
- apresentar a identidade da hamburgueria;
- facilitar o contato e os pedidos dos clientes;
- oferecer uma experiência agradável em computadores e celulares.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `inhdex.html` no navegador.

Também é possível usar a extensão **Live Server** no Visual Studio Code para visualizar a página com atualização automática.
